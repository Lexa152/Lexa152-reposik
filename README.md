## Выполняемые функции:
1. Частично скрытое отображение номеров банковских счетов и карт;
2. Работа с большими объемами данных транзакций (обработка массива данных генераторами):
   1. Фильтрация данных (выборка транзакций с заданной валютой операции);
   2. Легкочитаемое отображение массива данных (генератор, возвращающий описание каждой совершённой транзакции);
   3. Создание номеров банковских карт в требуемом диапазоне (генератор, принимающий диапазон, в пределах которого генерируются банковские номера карт);
3. Логирование выполняемых функций, времени и информации об ошибках;
4. конвертация валюты транзакции (из доллара или евро в Рубль).

## Примеры входных и выходных данных (в удобочитаемом виде):
1. Функционал частичного сокрытия номеров финансовых продуктов
   - Вход:
      - Visa Platinum 7000792289606361
      - Счет 73654108430135874305
   - Выход:
      - Visa Platinum 7000 79** **** 6361
      - Счет **4305
2. Работа с большими объемами данных (обработка транзакций):
   - образец транзакции, которая в больших количествах обрабатывается описываемым программным продуктом:
      - "id": 939719570
      - "state": "EXECUTED"
      - "date": "2018-06-30T02:08:58.425572"
      - "operationAmount":
         - "amount": "9824.07"
         - "currency":
            - "name": "USD"
            - "code": "USD"
      - "description": "Перевод организации"
      - "from": "Счет 75106830613657916952"
      - "to": "Счет 11776614605963066702
   - выборка транзакций с заданной валютой операции:
      - на входе список транзакций (образец приведён выше);
      - на выходе аналогичный список транзакций, валюта которых соответствует заданной;
      - формат параметра фильтрации: usd_transactions = filter_by_currency(transactions, "USD");
   - генератор, возвращающий описание каждой совершённой транзакции, работает так:
      - на входе аналогичный список транзакций;
      - на выходе описание каждой операции по очереди в виде:
         - Перевод организации
         - Перевод со счета на счет
         - Перевод со счета на счет
         - Перевод с карты на карту
   - генератор номеров банковских карт:
      - формат номера: "XXXX XXXX XXXX XXXX";
      - образец применения функции: "for card_number in card_number_generator(1, 5):";
      - формат вывода данных (print(card_number)):
         - 0000 0000 0000 0001
         - 0000 0000 0000 0002
         - 0000 0000 0000 0003
         - 0000 0000 0000 0004
         - 0000 0000 0000 0005;
3. При конвертация валюты в Рубль на вход подаётся транзакция (сообразная вышеприведённой), на выходе - вещественное число.
